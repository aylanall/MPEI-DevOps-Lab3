# Лабораторная работа 3: Нагрузочное тестирование массового создания событий

## Описание задания
Разработан веб-интерфейс для нагрузочного тестирования бэкенда `moscow-events`. Приложение позволяет массово создавать события пакетами, настраивая общее количество записей и размер пакета. В реальном времени отображаются общее время выполнения, средняя скорость создания, а также успех или ошибка каждого отдельного пакета.

## Используемые технологии
- **Фронтенд:** HTML, CSS, JavaScript (Vanilla)
- **Бэкенд:** [moscow-events](https://github.com/nelkor/moscow-events), образ `ghcr.io/nelkor/moscow-events:latest`
- **База данных:** PostgreSQL с расширением PostGIS, образ `postgis/postgis:17-3.6`
- **Веб-сервер:** NGINX (раздача статики и проксирование API)
- **Оркестрация:** Docker Compose

## Инструкция по запуску
1. Клонируйте репозиторий.
2. В файле `compose.yml` замените значение `change-me` на надёжный пароль в переменных `POSTGRES_PASSWORD` и `PG_USER_PASSWORD`. Пароли должны совпадать.
3. Выполните команду:
